NeuroStep - Execution Steps (Notepad)
=====================================

Goal:
Execution steps documented in a notepad file along with code and supporting files.


1) Prerequisites
----------------
- Node.js (v18+ recommended)
- npm
- Python 3.x (for model training script)
- Internet connection (for Firebase/Gemini services)

3) Install Dependencies
-----------------------
Open terminal in project root and run:

1. npm install


4) Configure Environment Variables
----------------------------------
Create a .env file in project root with Firebase values:

VITE_FIREBASE_API_KEY=your_key
VITE_FIREBASE_AUTH_DOMAIN=your_domain
VITE_FIREBASE_PROJECT_ID=your_project_id
VITE_FIREBASE_STORAGE_BUCKET=your_bucket
VITE_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
VITE_FIREBASE_APP_ID=your_app_id
VITE_FIREBASE_MEASUREMENT_ID=your_measurement_id

9) Core Execution Flow (Application)
------------------------------------
1. User logs in (Firebase Auth).
2. User plays games in src/games/.
3. Sessions/metrics are saved through src/services/db.js.
4. Aggregated game stats are fetched for dashboard.
5. Risk analysis runs from src/services/ml.js.
6. Dashboard presents score, insights, trends.
